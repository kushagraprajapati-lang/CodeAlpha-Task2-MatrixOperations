# 🚀 CodeAlpha Task 2: Matrix Operations in C

A modular, highly efficient C program designed to perform core matrix operations using **2D arrays** and **user-defined functions**. Developed as part of the **CodeAlpha C Programming Internship**.

---

## 🛠️ Features & Operations

The program implements the following operations with clean formatting:
1. **Matrix Addition ($A + B$)** — Adds two matrices element-wise.
2. **Matrix Multiplication ($A \times B$)** — Computes the product of two compatible matrices.
3. **Matrix Transpose ($A^T$)** — Flips a matrix over its diagonal (swapping rows and columns).
